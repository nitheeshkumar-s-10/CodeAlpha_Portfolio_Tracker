# Portfolio Tracker (Task 2)

A Python application to track stock investments, calculate total portfolio value, and generate summary reports.

---

## 📌 Features
* **Stock Input:** Add stock symbols and share counts interactively.
* **Portfolio Summary:** Calculates total holdings and investment value.
* **Export Data:** Saves summary reports to `portfolio_summary.txt`.
